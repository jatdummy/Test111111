# Issues Template

> Github Issues에 등록할 Issue의 양식.
>
> 사용자의 명시적인 명령 외에는 해당 양식을 기반으로 이슈를 작성한다.
>
> 섹션별 작성 규칙은 `Docs/Documentation/GithubIssueRule.md`를 따른다.

```markdown
<!-- 제목은 gh issue create --title로 입력한다 -->

## 배경 / 목적

- 

## 목표 (To-be)

-
-
-

## 작업 내용

-
-
-

## 완료조건 (DoD)

- [ ] 
- [ ] 
- [ ] 

## 특이사항

<!-- 해당 사항이 없으면 이 섹션을 삭제한다 -->
-
```
